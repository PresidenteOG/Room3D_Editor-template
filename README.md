# Room3D_Editor [TEMPLATE]

A desktop app for laying out rooms in 3D — place furniture from a catalog, plan in 2D, preview in
3D, save and reload your layout.

## Stack

Tauri 2 (Rust shell) + React + three.js.

## Running it

```bash
npm install
npm run tauri dev
```
